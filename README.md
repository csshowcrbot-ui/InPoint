## 🌟 系統核心亮點

- **日系簡約極致美學**：以森林青綠 (`#1A5E42`)、和紙白 (`#F4F7F5`) 與尊榮香檳金 (`#C89B3C`) 為基底，打造高質感視覺品牌體驗。
- **60 秒動態防作弊 QR Code**：採用 TOTP 時間窗口安全算法，大螢幕條碼每 60 秒自動刷新並平滑倒數，前次條碼立即過期，徹底防止遠端截圖代簽。
- **快速連續報到流水線**：報到櫃檯搜尋欄位具備薄荷綠高對比辨識，輸入員工卡號/姓名後按下 `Enter` 鍵立即一鍵報到，並自動清空欄位保持焦點，支援秒級連續作業。
- **卡號前導 0 自動忽略**：系統自動相容開頭含 `0` 的員工卡號（如輸入 `00601441` 與名冊 `601441` 均能 100% 精準匹配）。
- **主持人唱名確認與提詞聯動**：看板中每位到場貴賓具備專屬「📢 點擊唱名」按鈕，點擊後轉為「✓ 已唱名」，開場致詞提詞單即時連動。
- **Excel「桌號 / 組別」一鍵匯入**：名冊匯入自動對應桌號/組別，同仁手機掃碼簽到成功後立即顯示所屬用餐席位或小組（如 `VIP-1 主桌`、`第十三組`）。
- **全平台零依賴適配**：全面適配電腦螢幕、平板（iPad）、手機以及投影機大螢幕；自動相容 IIS 根目錄及子應用程式路徑（如 `/cscheckin/`）。

## 🛠️ 系統架構與技術棧

### 後端技術 (Backend)
- **平台核心**：.NET 8.0 (C#) Minimal APIs
- **資料庫存取**：Entity Framework Core 8.0 / Microsoft SQL Server
- **即時通訊**：ASP.NET Core SignalR（多端秒級狀態同步廣播）
- **安全算法**：HMAC-SHA256 TOTP-like 60 秒短效 Token 窗口驗證
- **打包模式**：Self-Contained (內嵌 .NET Runtime，目標主機無需預先安裝 .NET Runtime)

### 前端技術 (Frontend)
- **架構設計**：原生 HTML5 + Vanilla CSS3 + ES6+ 模組化設計（Single Source of Truth, SSOT）
- **QR Code 引擎**：內建標準 ISO/IEC 18004 QR Code 編碼庫（支援所有手機相機與 LINE 原生解碼）
- **即時匯流排**：BroadcastChannel + Server-Sent Event / SignalR 跨分頁與跨裝置無延遲同步
- **Excel 解析器**：SheetJS (XLSX) 高相容性前端試算表解析

## 📱 功能模組與介面說明

### 1. 報到處作業端 (Staff Check-in)
> 路徑：`index.html` ➜ 【📱 報到處作業端】

- **即時模糊檢索**：支援依「員工卡號」、「員工編號」、「貴賓姓名」、「所屬單位」或「手機號碼」即時篩選。
- **極速一鍵報到**：
  - 搜尋欄位採用薄荷綠高對比底色，聚焦時散發微光提示。
  - 輸入卡號後直接按下鍵盤 **`Enter`**，系統即刻完成簽到並播放成功音效。
  - 報到成功後搜尋欄位**自動清空並自動全選保留游標焦點**，櫃檯人員無需滑鼠操作即可連續刷卡報到。
- **撤銷確認防呆**：已報到人員若需取消簽到，具備二次確認對話框，避免誤觸。
- **現場臨時加退**：支援現場新增貴賓、編輯桌次及名單刪除（具備防呆機制）。

### 2. 主持人即時戰情看板 (Host Dashboard)
> 路徑：`index.html` ➜ 【🖥️ 主持人即時看板】

- **職級權重尊榮排序**：
  - 🥇 `Rank 1`：特級長官（總裁、院長、部長、局長、董事長等）
  - 🥈 `Rank 2`：副首長/民代/照專督導（副院長、議員、立委、副局長、照專督導、督導、照專等）
  - 🥉 `Rank 3`：主管專家/學者講師（科部主任、教授、醫師、學者、專家、講師等）
  - `Rank 4`：一般貴賓與醫院同仁
- **📢 唱名確認按鈕**：
  - 每張貴賓卡片右側設有活力橘黃色「📢 點擊唱名」按鈕。
  - 主持人於台上唱名介紹後點擊，按鈕即切換為靜態「✓ 已唱名」，提詞稿同步記錄，避免重複唱名。
- **開場致詞提詞稿自動生成**：
  - 系統即時彙整已到場之特級與各級長官，自動產生主持人開場致詞稿，並提供「📋 一鍵複製講稿」功能。

### 3. 現場大螢幕 60 秒動態 QR Code 投影 (Kiosk)
> 路徑：`kiosk.html`

- **大螢幕專屬視覺**：採用高對比沉浸式深綠漸層，支援右上角「⛶ 全螢幕投影」模式。
- **60 秒動態安全輪替**：
  - 伺服器端每 60 秒重新計算並派發一組安全 Token。
  - 前端具備 60 秒動態彩色進度條與倒數計時文字，倒數歸零立即產生新 QR Code。
  - 舊 QR Code 超過安全時間窗口後自動失效，防範遠端代簽。
- **現場戰情報告**：
  - 即時顯示已報到人數、全場出席率與總應到人數。
  - 右側即時滾動輪播最新到場貴賓（含 VIP 徽章、單位職稱與分配之**用餐桌次/組別**）。
- **活動場次切換**：頂部標籤提供下拉選單，可直接在大螢幕切換不同活動。

### 4. 參與同仁手機自助報到 (Mobile Self Check-in)
> 路徑：`self-checkin.html`

- **相機/LINE 掃碼即簽到**：同仁使用手機掃描現場大螢幕動態 QR 碼，自動帶入專屬安全 Token 進入報到頁。
- **卡號自動忽略前導 0**：輸入員工卡號（如 `00601441`）或姓名，系統自動精準匹配。
- **桌號/組別尊榮顯示**：簽到完成後跳出綠色成功畫面，並清晰提示大會所屬席位（如：*大會為您安排之席位：第十三組*）。
- **雙重端點自動容錯**：具備自動後端端點降級機制，無論伺服器後端版本如何，皆能 100% 確保手機自主簽到成功。

## 💾 資料庫架構與連線設定

系統支援 **Microsoft SQL Server**，設定檔位於 `appsettings.json`：

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=210.61.91.243;Database=ShowChwanEventDB;User Id=sa;Password=YOUR_PASSWORD;TrustServerCertificate=True;MultipleActiveResultSets=true"
  }
}
```

### 資料表結構 (Schema)

#### 1. 活動場次表 (`checkInEvents`)
- `EventId` (NVARCHAR(100), PK)：活動場次代碼
- `EventName` (NVARCHAR(200))：活動名稱
- `EventDate` (DATETIME2)：活動日期時間
- `Location` (NVARCHAR(200))：活動地點
- `Description` (NVARCHAR(MAX))：活動備註說明
- `IsActive` (BIT)：是否為當前進行中活動
- `CreatedAt` (DATETIME2)：建立時間戳記

#### 2. 貴賓與參與名冊表 (`checkInGuests`)
- `GuestId` (NVARCHAR(100), PK)：員工卡號 / 員工編號 / 貴賓代碼
- `EventId` (NVARCHAR(100), PK)：所屬活動場次代碼
- `Name` (NVARCHAR(100))：貴賓/同仁姓名
- `Organization` (NVARCHAR(200))：所屬單位/部門/科室
- `Title` (NVARCHAR(100))：職稱
- `RankWeight` (INT)：職級排序權重 (1=特級長官, 2=副首長/民代/照專督導, 3=主管專家/學者講師, 4=一般貴賓)
- `TableNo` (NVARCHAR(100))：**桌號 / 組別 / 席位**
- `IsCheckedIn` (BIT)：是否已完成報到
- `CheckedInAt` (DATETIME2, Nullable)：簽到時間戳記
- `CheckedInBy` (NVARCHAR(100), Nullable)：經手人 (例如：`現場報到處櫃檯 A` 或 `手機掃碼自主報到`)
- `QrCodeHash` (NVARCHAR(200))：專屬 QR 碼識別雜湊
- `Phone` (NVARCHAR(50), Nullable)：聯絡電話/手機
- `Notes` (NVARCHAR(MAX), Nullable)：備註事項

## 🚀 IIS 正式主機發布與部署步驟

本專案已配置完整一鍵發布腳本，步驟極為簡便：

### 第一步：一鍵打包發布
在開發環境的專案目錄下執行 PowerShell 腳本：
```powershell
.\publish.ps1
```
> 發布完成後，所有已編譯的程式庫、設定檔與前端靜態網頁會自動產出至目錄：
> 📂 **`G:\InPoint\publish\`**

### 第二步：複製至 IIS 網站目錄
1. 將 **`G:\InPoint\publish\` 資料夾內的所有檔案與資料夾** 全部複製並覆蓋至 IIS 伺服器網站根目錄（例如：`D:\Websites\cscheckin\`）。
2. （*若提示 `InPoint.dll` 檔案被佔用無法覆蓋，請在 IIS 管理員中將該「應用程式集區」點擊「停止 ➔ 覆蓋檔案 ➔ 啟動」即可*）。

### 第三步：開啟與驗證
在瀏覽器開啟網站首頁並按下 **`Ctrl + F5`**（清除本機舊快取）：
- 主控台：`https://www.csshow.org.tw/cscheckin/index.html`

## ❓ 常見問題與維護指南

### Q1：大螢幕動態 QR 碼可以離線運作嗎？
**可以**。系統前端內建標準 UTC 60 秒時間窗口算法與純 JavaScript QR Code 生成器，即使伺服器連線短暫不穩定，大螢幕仍能持續生成 60 秒動態 QR Code 與平滑倒數計時。

### Q2：員工卡號前面有 `0`（例如 `00601441`）如何處理？
系統後端與前端已全面內建智慧過濾器，自動去除前導零進行雙向比對。無論名冊輸入 `601441`、刷卡機讀出 `00601441` 或手機輸入 `00601441`，系統皆能 100% 精準匹配成功。

### Q3：如何切換至全螢幕投影？
在 `kiosk.html` 大螢幕頁面中，點擊右上角「**⛶ 全螢幕投影**」按鈕，或直接在鍵盤按下 **`F11`** 鍵，即可進入無邊框投影模式。

### Q4：若大螢幕開啟時網址出現 404？
請確認是否已將最新版 `publish/wwwroot/js/app.js` 部署至正式主機。最新版已內建動態目錄偵測，會自動加上 `/cscheckin/` 子應用程式路徑。

### Q5：建立新活動與刪除活動時的管理授權密碼為何？
為了防止非授權人員隨意新增、覆蓋或誤刪活動場次與所有貴賓名單，建立新活動與在管理中心刪除活動場次時，系統強制要求輸入管理授權密碼：`ZiEiHrpPq@`。
